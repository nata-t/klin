Fifteen marks, none of them a K

Each one has a single idea behind it: clean, the starter kit, or the full stack it builds. Star the ones you like, open any mark to see it in the browser tab, the terminal and the README, then let the duel narrow them down.

The current mark is a K, and the word next to it starts with one too, so the logo reads “K klin”. It happens everywhere the two meet: the website hero and header, the CLI banner, the README. None of these fifteen is a letter, so the name is only said once. The wordmark stays as it is.

Pick one of two

A knockout: two marks at a time, you keep one, until one is left. Fifteen marks take fourteen picks. The draw is random each time, so run it twice and see if the same mark wins.

Files: every mark and lockup is in concepts/logos/ as SVG. The page and the files are generated by node concepts/src/build.mjs; the terminal previews are pixelated automatically, the real pixel art gets drawn by hand for the mark you pick.
