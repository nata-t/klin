A new full-screen, grayscale wizard (a step indicator over the KLIN logo, which shrinks to fit the terminal; six compact, centered steps of text-chip lists, two groups side by side; live name validation in red; an amber warning when a security safeguard is switched off; and an always-visible explanation of the highlighted option above the key hints) replaces the old prompts, and every other command shares the same look: what `klin generate`, `add`, `remove`, `doctor` and `list` print is centered like the wizard's pages, whether they asked questions first or ran in one line. bun is now the first and default package manager, the closing next steps are centered too, and when Docker is missing, stopped or off-limits to your user (the Linux `docker` group), the next steps and `klin doctor` say how to fix it on your OS. New choices: NestJS or plain backends on Express or Fastify, optional CORS/Helmet/rate limiting (on by default), shadcn/ui in `apps/web` or a shared `packages/ui`, and shadcn's 18 theme colors (neutral first and default). NestJS projects validate with nestjs-zod DTOs built from the shared schemas; the landing page greets you with a terminal-style "klin"; i18n starts with English only; and `turbo dev` opens Turborepo's split-pane TUI with the Prisma client generated first and Prisma Studio running next to the web app and API (`db:studio` is a Turborepo task too). SQLite projects now include `packages/db/data/`, and their Prisma config writes `file:///` URLs so Prisma Studio can open them.
